# 🎨 BHHK THEME ENGINE v3.0

Custom animated Termux themes with your own name and colors.

## 🚀 Install

```bash
pkg install git -y
git clone https://github.com/arponshs/bhhk-theme.git
cd bhhk-theme
bash install.sh
```

## 🎯 Use

```bash
bhhk-theme
```

## ✨ Features

- 👤 Custom name + tagline + quote
- 🎨 14 colors for primary/secondary/accent
- 🎬 6 animation styles (Static, Typewriter, Glitch, Rainbow, Matrix, Wave)
- 📊 Display options:
  - Time
  - Date
  - IP address
  - Battery
  - Weather
  - Uptime
  - Storage stats
  - Quote
- 🎁 8 preset themes
- 📤 Auto-start on Termux launch
- 💾 Saved in `~/.bhhk_theme/theme.conf`

## 📝 How It Works

1. Run `bhhk-theme`
2. Choose **Create New Theme**
3. Enter your name, tagline, quote
4. Pick colors, border, animation
5. Choose what to display (toggle)
6. Saved! Preview shows instantly

Every time you open Termux, your custom theme shows up (if auto-start enabled).

## 📁 File

`~/.bhhk_theme/theme.conf` — your theme settings
