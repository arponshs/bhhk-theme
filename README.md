# 🎨 BHHK THEME ENGINE

Personal animated Termux themes. Use your own name, create custom colors, choose animation styles.

## 🚀 Installation

```bash
pkg install git -y
git clone https://github.com/arponshs/bhhk-theme.git
cd bhhk-theme
bash install.sh
```

## 🎯 Usage

```bash
bhhk-theme          # Open menu
bhhk-theme show     # Just show your theme
```

## ✨ Features

- 👤 Use your own name
- 🎨 Custom color picker (12 colors)
- 🎬 5 animation styles:
  - Wave
  - Typewriter
  - Glitch
  - Rainbow
  - Matrix
- 🎁 8 preset themes
- 📤 Auto-start on Termux launch
- 💾 Saved locally in `~/.bhhk_theme/`

## 📖 How to Use

1. Run `bhhk-theme`
2. Choose **Create Custom Theme**
3. Enter your name, tagline
4. Pick your colors
5. Choose animation style
6. Done! Run `bhhk-theme show` anytime

## 🎁 Preset Themes

- 🌊 Ocean Blue

## 📤 Auto-Start

Enable **Auto-Start on Termux** in menu → every time you open Termux, your theme shows up automatically.
